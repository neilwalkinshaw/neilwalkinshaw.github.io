Research

Broadly my research interests lie in the testing and analysis of software and cyber-physical systems.
  • 📚 My publications can be found here: Google Scholar | DBLP

    • State machine inference and analysis

    I have a longstanding interest in the development of techniques that can help to understand the sequential behaviour of systems when there isn't a prior model available. My key contributions in this area include:

  • Extended Finite State Machine (EFSM) inference - a technique to infer state machines with guards (Journal of Empirical Software Engineering, 2016) and even full computational EFSMs with state transition functions (ICSME'16).
  • LTSDiff - an algorithm to graphically compare two state machines to each other (ACM Transactions on Software Engineering Methodology, 2013).
  • Subjective Opinion State Machines - A generalisation of Probabilistic State Machines that uses Subjective Logic to model second-order uncertainty (which captures the uncertainty surrounding a given probability). We show how these can be used to improve accuracy in inferred state machines ( IEEE Transactions on Software Engineering, 2023).

    • Causal Software Engineering

    I am interested in developing techniques to support the testing of that are traditionally hard to test (e.g. complex input spaces, cyber-physical systems, systems with long execution times, etc.). My research tends to focus on the application of concepts and techniques rooted in Machine Learning and probability theory. In recent years much of my research has focussed on the application of Causal Inference to test causal relationships between inputs and outputs in scientific software models (funded by the EPSRC CITCOM project). I have produced a separate page detailing our research on the CITCOM project.
